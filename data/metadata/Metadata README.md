# Metadata

`samples.metadata.20250122.csv` contains metadata associated with all FCS files included in this analysis. Metadata link each FCS file to the corresponding experimental run, tissue, animal, treatment group, and infection outcome. Values are recorded as `NA` when a variable was not collected or was not applicable to a given sample.

## Variables

| Variable | Description |
|-----------|-------------|
| `FCSFileNames` | Original filename generated by the flow cytometer. |
| `Sample` | Processed sample name generated during FlowJo data cleaning and export. |
| `Experiment` | Experimental run identifier (1–41). |
| `Tissue` | Tissue from which the sample was collected (e.g., Lung, Nasal Tissue, Spleen, Inter-run QC). |
| `Mouse Number` | Mouse identifier within an experimental run. Quality control samples are labelled `QC`. |
| `For_Vlookup` | Concatenation of `Experiment` and `Mouse Number`, used as a run-specific identifier. |
| `UniqueMouseID` | Unique identifier assigned to each mouse across all experiments. |
| `Treatment` | Treatment group assigned to the mouse. |
| `Timepoint` | Tissue collection timepoint (hours post-treatment and/or challenge). |
| `Sex` | Biological sex of the mouse (`M` or `F`). |
| `Hh Dose` | Retrospectively quantified *Haemophilus haemolyticus* inoculum (CFU/mL) administered to the mouse. |
| `NTHi Dose` | Retrospectively quantified non-typeable *Haemophilus influenzae* (NTHi) inoculum (CFU/mL) administered to the mouse. |
| `NTHi MET CFUml` | NTHi colony-forming units (CFU/mL) recovered from middle ear tissue. |
| `Log10(CFUml)` | Base-10 logarithm of NTHi CFU/mL recovered from middle ear tissue. |
| `Developed OM` | Otitis media outcome classification. Samples are classified as `OM` (developed otitis media) or `nOM` (did not develop otitis media). |

## Treatment Abbreviations

| Abbreviation | Description |
|--------------|-------------|
| `Hh` | *Haemophilus haemolyticus* |
| `NTHi` | Non-typeable *Haemophilus influenzae* |
| `IAV` | Influenza A virus |
| `Pam1ug` | 1 µg Pam2CSK4 treatment |
| `Pam10ug` | 10 µg Pam2CSK4 treatment |
| `Saline` | Vehicle control treatment |

Combination treatments are represented by concatenation of treatment names (e.g., `Hh+IAV`, `Pam1ug+IAV+NTHi`).

## Timepoints

Timepoints are recorded in hours and include:

- 2 h
- 6 h
- 24 h
- 48 h
- 72 h
- 96 h
- 144 h

## Quality Control Samples

The metadata file contains inter-run quality control (QC) samples used to assess flow cytometry consistency across experiments. These samples are identified by:

- `Tissue = "Inter-run QC"`
- `Mouse Number = "QC"`
- `Treatment = "QC"`

Experimental metadata fields are recorded as `NA` where not applicable.

## Notes

- `NA` indicates that a variable was not collected, unavailable, or not applicable to a given sample.
- `Mouse Number` values are unique only within an individual experiment.
- `UniqueMouseID` provides a unique identifier across all experiments.
- Dose values were retrospectively quantified from viable counts of administered inocula.
- Otitis media outcomes are based on NTHi recovery from middle ear tissue relative to the study-defined limit of detection.
- Each row corresponds to a single tissue sample represented by one FCS file.
