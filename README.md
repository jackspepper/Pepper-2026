# Pepper *et al.* 2026
---

This repository contains the code and data for the paper [Mucosal immune cell priming by intranasally delivered *Haemophilus haemolyticus* is associated with heterologous protection against influenza and nontypeable *Haemophilus influenzae*](https://www.frontiersin.org/journals/immunology/articles/10.3389/fimmu.2026.1855464/full#s5) published in *Frontiers in Immunology*.

The raw data supporting the conclusions of this article will be made available without undue reservation. Please contact either the corresponding author or the first author for access to the data. The code used for analysis is available in this repository.

Front. Immunol. 17:1855464. doi: 10.3389/fimmu.2026.1855464
